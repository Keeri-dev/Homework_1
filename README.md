## Issues Identified 
The WAVE accessibility evaluation tool detected several errors located here:

- The hashtag banner text color and background color.
- Hashtag banner structure by wrapping it in its own class. 
- The footer section text contrast agaisnt the background. 
- H1, H2, H3 contrast for text color.
- ALT text missing from image
- Did not use headers h1 to h2 in logical sequence 


All of these elements did not meet WCAG color contrast recommendations.The heading skip error makes it harder for screenreader to read correctly. This all made it overall more difficult for users who need accesibility options. 

## Accessibility Standards 

These changes were all made to improve compliance with WAVE Guidlines and Success Criteria. 

## Outcome 

After implementing all changes:

- All contrast issues were resolved.
- Text readability was improved. 
- Overall better accessibility achieved through WAVE compliance.
- Changes to headers improved accesiblity for screen readers.
